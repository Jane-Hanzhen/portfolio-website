# Hospital Spatial Intelligence Platform

## 项目概览

**项目名称：** Hospital Spatial Intelligence Platform\
**项目类型：** Full-stack Web GIS / Spatial Data Product\
**项目时间：** 2024.10 - 2024.12\
**项目定位：** 面向医院信息采集与空间分析场景的全栈 GIS
平台，通过移动端众包采集、空间数据服务和可视化分析，实现医院位置、排队状态及环境信息的动态管理。

------------------------------------------------------------------------

# 1. 项目背景与问题

传统医院信息通常依赖官方发布或人工统计，存在：

-   医院服务状态更新不及时；
-   排队时间、现场环境等动态信息难以获取；
-   缺少空间化的数据展示方式，难以辅助管理人员进行区域分析。

因此，本项目设计并实现一个基于 Web GIS
的医院信息采集与分析平台，通过用户位置服务和众包机制收集医院实时状态，并通过地图与
Dashboard 进行空间可视化。

------------------------------------------------------------------------

# 2. 产品解决方案

平台由三个核心模块组成：

## 2.1 移动端众包采集应用

面向普通用户：

-   自动获取用户 GPS 位置；
-   根据用户当前位置匹配附近医院；
-   在满足位置稳定条件后触发信息采集；
-   用户提交医院排队长度与环境描述。

核心流程：

    用户位置获取
            ↓
    连续位置记录
            ↓
    空间距离判断
            ↓
    Proximity Alert 触发
            ↓
    提交医院状态信息
            ↓
    写入空间数据库

------------------------------------------------------------------------

## 2.2 空间数据 API 服务

构建 Node.js + Express RESTful API，为前后端提供统一数据服务。

主要功能：

-   医院位置创建与查询；
-   医院空间数据 GeoJSON 服务；
-   众包状态数据存储；
-   用户贡献数据统计。

系统架构：

    Frontend Application
            |
            |
    RESTful API
            |
            |
    Node.js Express
            |
            |
    PostgreSQL / PostGIS

------------------------------------------------------------------------

## 2.3 空间分析 Dashboard

面向管理和分析场景：

-   使用 Cesium 构建 3D 空间可视化；
-   根据医院排队状态动态展示空间分布；
-   点击医院查看历史报告；
-   联动地图、统计图表和数据详情。

实现从：

    空间数据采集
            ↓
    数据管理
            ↓
    空间分析
            ↓
    可视化决策支持

的完整数据闭环。

# 3. 核心技术挑战与解决方案

## 3.1 GPS 定位稳定性校验

### 挑战

移动端 GPS 存在定位漂移问题，简单根据单次距离判断容易导致误触发。

### 解决方案

设计基于连续位置记录的稳定性判断机制：

-   保存用户最近 5 次 GPS 位置；
-   计算用户与医院点之间的距离变化；
-   仅当用户持续接近目标医院时触发采集流程。

该机制降低了移动环境下由于 GPS 噪声导致的错误触发。

------------------------------------------------------------------------

## 3.2 空间数据库与 API 设计

### 挑战

需要同时管理：

-   医院空间位置；
-   用户提交记录；
-   历史状态变化。

### 解决方案

基于 PostgreSQL/PostGIS 设计空间数据模型：

-   使用空间字段存储医院 POINT 数据；
-   通过 REST API 实现客户端与数据库交互；
-   返回 GeoJSON 格式支持地图渲染。

------------------------------------------------------------------------

## 3.3 多端 GIS 应用设计

### 挑战

同一应用需要适配：

-   移动端采集场景；
-   浏览器端医院管理场景；
-   Dashboard 分析场景。

### 解决方案

采用响应式 Web GIS 架构：

-   Leaflet 实现地图交互；
-   Bootstrap 支持多屏幕适配；
-   模块化 JavaScript 管理地图、定位、图层和可视化功能。
